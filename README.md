# 🚌 Bus Traffic Sort 3D (Яндекс Игры)

Готовая 3D гиперказуальная игра-головоломка, оптимизированная и подготовленная для публикации на платформе **Яндекс Игры**.

## 🎮 Особенности проекта
1. **Геймплей**:
   - Кольцевая очередь разноцветных 3D-пассажиров.
   - Парковочные слоты остановки с динамической вместимостью автобусов.
   - Пробка с блокирующими друг друга автобусами и системой проверки направления выезда (Raycast Collision).
   - Анимированная посадка пассажиров и салюты при заполнении автобусов.
2. **Бустеры**:
   - **Sort (Ур. 2)** — мгновенная сортировка пассажиров под цвета автобусов в слотах.
   - **+Slot (Ур. 3)** — разблокировка дополнительного VIP-места.
   - **Heli (Ур. 5)** — вылет любого заблокированного автобуса по воздуху прямо в слот.
3. **Соответствие требованиям Яндекс Игр**:
   - Интеграция **SDK v2** (`https://yandex.ru/games/sdk/v2`).
   - Автоматический **Mock SDK** для комфортной локальной разработки без ошибок.
   - Вызов **LoadingAPI.ready()** сразу после старта игры.
   - Межстраничная реклама (Interstitial) между уровнями.
   - Реклама за вознаграждение (Rewarded Video) для удвоения монет и бустеров.
   - **Автоматическая пауза игры и звука при переключении вкладок (`visibilitychange`)** и во время показа рекламы.
   - Облачные сохранения (`ysdk.getPlayer()`) с резервным `localStorage`.
   - Процедурный синтез звуков (Web Audio API) — мгновенная загрузка < 1 секунды без внешних аудиофайлов.

## 🚀 Как запустить локально
Откройте папку проекта в любом локальном сервере (например, Live Server в VS Code или Python HTTP-сервер):
```bash
python -m http.server 8080
```
И откройте в браузере: `http://localhost:8080`

## 📦 Как опубликовать в Консоли Яндекс Игр
1. Запакуйте все файлы из папки `bus-traffic-sort` (`index.html`, `style.css`, папку `js/`) в обычный `.zip` архив (без вложенной корневой папки, `index.html` должен быть в корне архива).
2. В консоли разработчика Яндекс Игр перейдите в раздел **Черновик** -> **Файл с игрой** и загрузите zip-архив.
3. Игра автоматически подключится к боевому Yandex SDK v2!
